# Multi-Class Benchmark Classification Pipeline (Iris Dataset)

## Project Overview
This project implements a multi-class classification pipeline using the Iris dataset. The objective is to classify Iris flower species based on sepal and petal measurements using machine learning algorithms.

## Problem Statement
Build an end-to-end classification pipeline by preprocessing the data, splitting it into training and testing sets, training machine learning models, and evaluating their performance using standard classification metrics.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Machine Learning Models
- Logistic Regression
- Decision Tree Classifier

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- Classification Report

## Results
Both Logistic Regression and Decision Tree models achieved high classification accuracy on the Iris dataset. The confusion matrix and classification report were used to compare model performance.

## Conclusion
This project successfully demonstrates a complete machine learning classification workflow, including data preprocessing, model training, evaluation, and performance comparison using the Iris dataset.
